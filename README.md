# Funnel Optimization

## Project Overview
This project models a funnel-based analytics workflow for session, event, and conversion analysis.

## Data
The project includes local CSV files for sessions, events, transactions, and abandonment-related records used to analyze conversion behavior and funnel performance.

## Solution
A Power BI reporting model was built to track funnel stages, drop-offs, conversions, and operational KPI views.

## Technologies
- Power BI
- CSV source files
- semantic model design
- DAX reporting

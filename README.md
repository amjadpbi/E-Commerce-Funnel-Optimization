# E-Commerce Funnel — Conversion & Cart Abandonment

A funnel-analysis portfolio project built around session, event, transaction, and abandonment data.

## Project Overview
This project models customer progression through a conversion funnel using Power BI and local CSV data. It focuses on stage performance, drop-off analysis, and conversion pattern assessment.

## Business Context
This is a self-initiated learning analytics project using synthetic/local funnel and transaction data. The repository reflects an educational analysis scenario rather than a real production funnel implementation.

## Problem
The goal was to transform raw event and session data into a clear funnel view so conversion and abandonment trends could be observed across the customer journey.

## Solution
The project contains a PBIP, PBIX artifact, report definitions, and semantic model designed to analyze funnel steps, conversion rates, abandoned sessions, and transactional outcomes.

## Data
- Source type: CSV files
- Data nature: synthetic/local session and funnel dataset
- Key files: sessions.csv, funnel_events.csv, transactions.csv, cart_abandonment.csv

## Technical Approach
- load event/session transaction files into model
- define funnel stages and conversion metrics
- connect fact tables through relationships
- build DAX measures and report visuals for step-by-step performance analysis

## Key Analytical Areas
- funnel conversion analysis
- abandonment tracking
- transaction and session behavior
- stage-level performance review

## Evidence / Scope
The repository includes the Power BI project files, data files, and semantic model definitions. It is best treated as an educational funnel analytics model rather than evidence of a live business process.

## Limitations
- synthetic/local data only
- no live operational deployment evidence
- modeled for learning and demonstration purposes
